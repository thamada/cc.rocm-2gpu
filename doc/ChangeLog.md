## 2026-11-08 06:55:02

2 GPU の VRAM 転送帯域と、2 GPU 同時の Host↔VRAM 読み書き帯域を測るプログラムを追加し、`doc/` に現行設計を書いた。

- `p2p_bw.hip` と `Makefile` を追加した。`make run` がビルドして計測を始める。既定は GPU 0 と GPU 1、最大 1024 MiB、反復回数はサイズごと自動。
- GPU 間は、ピアアクセスが両方向で使えるとき `hipMemcpyPeerAsync`、使えないときピン留めホストのダブルバッファ（既定チャンク 8 MiB、`P2P_CHUNK_MB` で変更）である。単方向 2 本と、同時の双方向合計を測る。
- Host↔VRAM は、書き込みと読み出しを別に測る。各サイズで各 GPU の単独帯域と、2 GPU 同時の各帯域、両方が終わるまでの合計帯域を出す。ホストメモリは GPU ごとにピン留めする。
- 最大サイズの転送結果を 32bit パターンで照合する。不一致なら終了コード 1。計測の意味、時間の取り方、帯域の式は `p2p_bw.hip` 冒頭と各関数のコメント、および `doc/design.md` に書いた。

このホスト（Radeon AI PRO R9700 が 2 枚、直接リンクなし、ピアアクセス不可）ではホスト経由で動き、検証は通った。`make run` の大きいサイズでは、GPU 0→1 が 7.45 GB/s、GPU 1→0 が 9.30 GB/s、双方向合計が 11.09 GB/s（いずれも 1 GiB）だった。Host→VRAM は単独 12.95 GB/s と 11.12 GB/s、同時合計 20.75 GB/s。VRAM→Host は単独 11.83 GB/s と 9.04 GB/s、同時合計 19.48 GB/s。
